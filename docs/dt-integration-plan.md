# DT 統合計画 — 3D をカメラセンサーとして本番系に組み込む

> 作成: 2026-08-30 / v1
> 位置づけ: [`implementation-plan.md`](implementation-plan.md) フェーズ E の展開。
> 前提: **全部クラスタで実行する（T2）**。シムは Node の headless、3D は headless Chromium。
> 現状の DT コードの実態は 2026-08-30 の棚卸し（camera_sensor / scene_builder / main.js の読解）に基づく。

---

## 0. 結論 — 既存の DT は「そのままでは繋がらない」

| 観点 | 現状 | 本番に必要な形 |
|---|---|---|
| DT ページの中身 | 固定の舵・推力で船を動かす**独立した世界**。勝敗もスケジューラも無い | シムの状態を**外から受け取って描く**だけの装置 |
| カメラ出力 | 表示用 canvas をそのまま `toDataURL`。解像度＝窓サイズ×2 | 固定 640×360 のオフスクリーン描画 |
| 船体 | 全艇同じ形 | **艦種で見分けられる形** |
| カメラの向き | 船首固定 | 指示された相手へ向ける |
| 呼び出し方 | ブラウザ内ループ | Node から「この状態でこの艇から撮れ」と呼べる |

DT は表示装置として作られており、センサーとして呼び出す口が無い。これが最大の TODO。

---

## 1. 構造的な決定 — DT を「状態 → 画像」の純関数にする

### 選択肢

| 案 | 内容 | 評価 |
|---|---|---|
| (a) DT ページの中でゲームを回す | DT に swarm-sim のループを移植し、ブラウザで全部動かす | 決定論（await）が崩れる。二つ目のゲームループを保守する |
| **(b) レンダサービス** | シムは Node。DT ページは `render(状態スナップショット, 観測艇ID) → PNG` を公開し、Puppeteer 経由で呼ぶ | **採用**。World 統合をしない（roadmap §9）まま、3D をセンサー実装（system-architecture E9）にできる |
| (c) Three.js を Node で直接 | headless-gl 等 | 依存が重い・WebGL 互換の罠。見送り |

### (b) の契約

```
入力:  { ships: [{id, faction, shipClass, x, y, heading}], observerId, lookAtId? }
出力:  PNG data URL（640×360 固定）
```

- **状態を渡すだけ**で、DT は自分の World を持たない。既存の `three.updateShips(entities)` が
  まさにこの入力形（`state.snapshot()` 互換）を取るので、土台は流用できる。
- シムから見れば `world.observe(scoutId, 'camera')` が非同期になるだけ。
  `CameraSensor` の実装を「Puppeteer 越しにレンダサービスを呼ぶ」ものに差し替える。
- レンダの実時間は `renderS` として**別ステージで実測記録**し、宣言値へは書き戻さない（time-model §12.5）。

## 3. 順序と依存

```
A-2 識別台帳 ──┐
D-6/D-7 固定解像度 ──┐
D-10/D-11 艦種形状 ──┼─→ D-13 識別距離の実測 ─→ 設計値の確定（game-design §4 更新）
D-1..D-5 レンダサービス ─┘            │
S-1 画像入力 ─────────────────────────┼─→ S-2/S-3/S-4 接続 ─→ E 完了
D-14/D-15 クラスタ実測 ───────────────┘
```

**最初にやるのは D-6 と D-10**（センサーとしての画が成立しないと何も測れない）、
次に **D-13 の実測**。1200 m という数字はこの実測が出るまで設計値ではなく仮説である。

## 4. 完了条件

`node scripts/headless_run.js --scenario flag_defence_squadrons --scout vlm --episodes 1 --llm-url <vllm> --model <VLMモデル>`
が完走し、ログに `render` と `infer` の段別実測、識別台帳への VLM 由来の書き込み、
それに基づく艇の離脱が 1 件以上現れる。
