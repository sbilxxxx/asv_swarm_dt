# このマシンの GPU 使用取り決め（掲示 / advisory）

更新: 2026-09-06  記入者: ben_ben

スケジューラ（Slurm/k8s）が無く、root も使えないため、**強制力のある割り当ては存在しません。**
以下は協調のためのお願いです。新しく使う方は、都合が悪ければ ben_ben に連絡して変更してください。

## 現在の分割

| グループ | GPU | ollama | 用途 |
|---|---|---|---|
| vlm | 0,1,2,3 | 127.0.0.1:11434 | VLM / 画像航行 |
| sim | 4,5,6,7 | 127.0.0.1:11435 | マルチエージェント実験 |

NVLink が無く GPU0-3 と GPU4-7 が別 NUMA（`nvidia-smi topo -m` が SYS）なので、
この境界で切っています。

## ben_ben 側が守っていること

- ジョブ実行前に空き VRAM を検査し、足りなければ待機→スキップする（CPU退避で粘らない）
- シムジョブは同時最大3本まで並走させる（結果はGPU競合の影響を受けない設計のため）。
  レイテンシ計測だけは単独実行
- **他ユーザーのプロセスを同じ GPU 群に見つけたら、自分のジョブを止めて譲る**（`gpujob` の YIELD）
- キューが空いている間はモデルをアンロードして VRAM を返す（居座らない）
- `OLLAMA_KEEP_ALIVE=20m`、`num_ctx` は用途に合わせて 8192 に制限

## お願い

- 使う GPU 番号をこのファイルに追記していただけると衝突を避けやすいです
- `nvidia-smi` で他人のプロセスが載っている GPU は避けてください
- 大きなモデルを常駐させる場合、`num_ctx` を実際の用途まで絞ってください
  （既定のまま 128K〜256K で載せると、7B のモデルでも 85GB を占有します）
